# Review decisions in 0.5.0

| Previous tendency | Decision | Demonstration |
|---|---|---|
| Treat a witty opening as the normal way to start | Tone follows the task; a direct answer or neutral event is sufficient | A plain personal reply |
| Let a useful analogy stand in for an explanation | Connect mechanism and consequence; distinguish a proposal from a source fact | An analytical note with bounded conclusions |
| Make fiction finish with a quip or explained moral | Give participants different intentions and end the current scene move | A sober scene without a punchline |
| Explain an unsupported feature by inventing a reason | State the actual limit; explain its cause only when supplied | A factual announcement with an explicit scenario brief |
| Carry sample facts into the next task | Include before/after scenario provenance and retain the source boundary | All four new demonstrations |

The review combines an inventory of eligible reference material with stratified
close reading. Genre/source families, related versions and attributed quotations
are distinguished. It is not a claim that every word was read manually or that
raw corpus size measures stylistic influence. Public demonstrations are newly
written fictional fixtures, not excerpts or real model-evaluation outputs.
